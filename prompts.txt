CDN.

Debo crear las siguientes plantillas dentro de:

templates/academic/

- base.html
- home.html
- courses.html
- students.html

Requisitos:

1. base.html debe contener la estructura general del sitio y
   un menú de navegación.

2. El menú debe tener acceso a:
   - Inicio
   - Asignaturas
   - Estudiantes
   - Panel de Administración de Django.

3. Usar Bootstrap mediante CDN, sin instalar Bootstrap como
   paquete de Python.

4. home.html debe ser la página de inicio del Sistema de Gestión

   hacia Asignaturas y Estudiantes.

5. courses.html debe mostrar las asignaturas registradas y el
   profesor asociado a cada una.

6. students.html debe mostrar los estudiantes registrados.

7. La interfaz debe ser limpia, sencilla, responsiva y adecuada
   para una aplicación académica.

8. Las plantillas deben extender base.html para reutilizar la
   navegación y estructura general.

9. Las páginas deben consumir los endpoints de Django REST
   Framework en segundo plano mediante JavaScript y fetch(),
   sin enviar al usuario directamente a las páginas de la API.

10. En las páginas de Asignaturas y Estudiantes debe existir
    CRUD completo:
    crear, consultar, editar y eliminar registros.

11. Las acciones de edición y eliminación deben aparecer como
    botones visibles en cada registro.

12. Para las operaciones POST, PUT y DELETE se debe utilizar
    el token CSRF de Django.
